## 已完成的基线

使用 14 个开发提示，每个提示 4 个固定种子，共生成 56 张 432×432 图像。提示覆盖组合约束、人物、自然、插画与产品场景。沿用官方 50 点 shifted Euler flow 时间网格及 CFG 5.0；从实际组件调用次数核实，每张图有 49 次模型速度预测。56 个任务均有图像文件，尺寸检查通过，错误数为 0。这个开发集用于工程与后续诊断，不作论文测试集。

服务器共有 8 个编号的 RTX 3090，其中物理 GPU 5 返回 `Unable to determine the device handle`。本次使用了其余 7 张健康卡：0、1、2、3、4、6、7。每卡完成 8 张图。设备 5 故障导致 CUDA 数字编号错位；卡 6、7 最终使用 GPU UUID 定位并补齐其分片。物理卡 1 原先已有约 4GB 显存占用，其单图延迟稍高。

排除每卡一张插桩图后，49 张图的耗时与显存统计如下：

| 指标 | 中位数 |
|---|---:|
| 单图总耗时 | 12.293 秒 |
| 输入准备 | 0.034 秒 |
| 49 次去噪速度预测 | 12.134 秒 |
| VAE 解码与 PNG 保存 | 0.133 秒 |
| 峰值已分配显存 | 8.109 GB |
| 峰值预留显存 | 8.642 GB |

各卡未插桩图的单图中位耗时：GPU 0 为 12.041 秒、1 为 13.627 秒、2 为 12.730 秒、3 为 12.396 秒、4 为 12.061 秒、6 为 12.293 秒、7 为 12.039 秒。每卡的原始逐图记录见 `logs/metrics_gpu*.jsonl`；汇总和可复核 CSV 见 `results/`。

首图使用 CUDA event 对组件插桩，7 卡中位 GPU 时间为：语言骨干 6.530 秒、视觉语义 Transformer 1.778 秒、视觉嵌入 0.091 秒、融合层 0.052 秒、flow 头 3.559 秒。以上是 49 次速度预测累计的组件时间，含插桩开销，不应直接相加作为未经插桩的墙钟时间。按 49 次调用粗略折算，每次生成头约 73 毫秒、语义 Transformer 约 36 毫秒；这给“同一中间状态重新执行生成头”的反馈预算提供起始量级，实际新增模块与缓存规则仍须另测。

## 训练成本试测

从 14 张基线图经官方 Wan VAE 重新编码潜变量，用官方 flow 路径构造训练对，冻结基础模型，仅在生成头注意力的 q/v 投影训练 rank-16 LoRA。可训练参数 1,064,960 个，微批量 1，单卡 3090 完成 200 个优化步骤。排除预热后，每步中位耗时 0.1835 秒，峰值已分配显存 8.388GB，预留显存 8.642GB。

这项试测只回答“当前硬件是否承担得起这种轻量反向传播”。数据来自基础模型自身图像，训练损失跨随机噪声与提示波动，不能用首尾损失证明图像质量、人类偏好或多样性改善。尚未训练研究方案中的观察器与反馈器。

## 图像检查与下一步

联系图 `results/contact_sheet.jpg` 按同一提示排列四个种子，便于观察主题一致性和构图差异。抽查 `composition_01_seed101.png` 可见视觉质量尚可，但一只红杯落在蓝盘上，未满足“两只红杯都在盘子左侧”。这一类失败可用于下一阶段“同一潜变量状态、不同反馈”的成对延续。联系图只作视觉抽查，尚无人类偏好盲评，也未计算经过质量筛选的有效多样性，因此不能据此声称任何目标提升。

下一阶段应使用本阶段的成本记录选择检查点，扩展到预先分层的 128 个开发提示，在中间状态比较只读文本、语义特征、语义加空间生成特征及像素预览的观察能力，再从相同潜变量状态测量反馈的修复率、破坏率、视觉质量、人评偏好和同提示词多样性变化。

## 复现说明

代码入口及参数见 `README.md`。本机已有 Show-o2 环境缺少 `decord`，本实验在项目目录 `deps/` 安装 `decord==0.6.0`；其 `torch.compile` 导入与该环境的 `functorch` 不兼容，运行时使用 `TORCHDYNAMO_DISABLE=1`。原始模型检查点包含 910 个张量，语言、语义、融合与 flow 头权重均存在。为避免模型构造时重复读取完整 Qwen 权重，`prepare_checkpoint.py` 用硬链接保留官方 Show-o2 权重，把 Qwen 配置/tokenizer 与 SigLIP 路径指向本地，并设置 `load_from_showo=True`；加载后检查无未实例化的 meta 参数。推理输出为安全检查器处理前的原始图像，所有基线方法后续都应采用同一约定。

若要复核结果，运行 `aggregate_results.py --work /home/shy_23/iterative_visual_stage1_20261003`。它验证 56 个 `(提示, 种子)` 任务无缺漏与重复、全部 PNG 尺寸正确，然后重建 JSON、CSV 和联系图。
