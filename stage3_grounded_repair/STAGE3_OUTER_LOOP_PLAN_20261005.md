# 第三阶段：外层与内层共享循环（2026-10-05）

用户新增要求已纳入第三阶段：同时研究语言/理解骨干 Transformer 的循环与 flow head 的循环。核心问题是理解证据怎样改变后续生成计算，并通过共同的可训练表示改善理解。

## 实际架构与实现位置

已逐行核对当前服务器官方 Show-o2 forward。每次速度预测先做双路径视觉融合，经过 Qwen，再将联合隐藏状态通过 diff_proj 送入 flow head。实际模型为 26 层语义视觉编码器、28 层 Qwen 骨干、10 层 flow head。Qwen 在每次速度预测中执行，并非只在生成开始时编码文字。

因此分开研究两种计算：外层重访改变文字与视觉的联合表示，内层重访改变当前速度场的计算。MMU 判断来自同一模型，但增加 MMU 检查次数本身不构成 Transformer 循环。

## v31：已实现并完成真实接口验证

outer_shared_revisit.py 复用原 Qwen block26/27（索引从0开始），在原 block25 输出后插入证据条件重访，然后继续原 block26/27。适配器读取 MMU 的目标/反向判断表示、当前视觉 token 内容及二维坐标，预测有界 token 调制。原骨干权重冻结；新增可训练参数 1,192,840。

当前接口采用零校准共享残差：设 G 为原 block26/27 组成的共享栈，输出 h + M·[G(h+δ)-G(h)]。M 仅选条件分支视觉 token，δ 由证据和当前视觉内容预测。零初始化时两次共享计算相减，接口严格恢复原状态；后续原骨干仍可将视觉变化传播到文本查询位置。它是共享块循环的可训练接口原型，尚未完成压缩骨干或 ELT 式多循环联合训练。

在4个干预 flow 时刻，每次执行两次共享栈，即新增16次 Qwen block 调用。外层被修改后，旧 inner block7 prefix 和旧 KV 均失效；v31 禁用 KV，14次剩余速度全部从新输入完整重算。

实际5项 CPU 接口测试通过。真实模型14次终点反传通过，零干预终点 latent 与原捕获基线逐元素严格相等；基础参数无梯度，共享 core hash 不变，适配器梯度有限且非零。峰值显存14.8119 GiB，反传段11.5747秒；这不是完整生成耗时。optimizer 更新0次，没有终图评测，不构成生成质量或理解提升结果。原始记录在 outer_revisit_gradient_v31。

## 固定比较与下一步训练

比较基线、仅外层循环、仅内层循环、外层与内层联动四组。固定提示、seed、检查时刻、ODE 网格、终点损失和真实保真样本；初始公共映射与训练抽样匹配。每组均保留未训练零操作、乱序证据、反向证据对照。外层与内层块的宽度、注意力结构和计算不同，不能用相同 block 数声称等 FLOPs。

目前已扩展得到3个独立合格TRAIN教师和35个真实正确保真态。v33外层50步pilot的10终图均未语义翻正，质量略降。v38以相同公共证据初始化、数据、抽样和终点目标完成外层/内层/双层联动各100步，联动共享EvidenceEncoder；固定step100的6态×5动作×3组90张TRAIN诊断v39已完成；全部证据动作0翻正，正确证据平均HPS三组均下降。当前新增计算仍未证明修复或总体质量成功。三组成本不同，必须另做成本匹配比较。

当前联动新增参数1,983,624，较独立内外层适配器减少599,688，但原骨干全部保留，总模型参数仍增加。完整14次终点梯度、严格零操作和共享证据映射梯度连通已通过，均不能替代独立终图结果。

联动训练需要两种监督：生成端对完整终点的质量守门教师及真实正确态保真；理解端对相同共享骨干的 MMU 答案/关系证据和 AR next-token 保真。理解任务的前向需同样禁用不合法 KV，并采用正确的任务 token 与注意力掩码。只冻结骨干并检查其 hash，不能证明理解能力得到保留或提高。

固定修复器通过独立 val 后，再训练计算路由，形成“画到一半→共享理解检查→选择外层/内层/双层循环→继续生成→重新检查”的闭环。路由只读取当前或已有早期状态，不读取终图标签；训练可以用 TRAIN 终点评分作为监督。先验判断必须和乱序/反向证据比较，区分有方向的证据驱动修复与普通额外计算。

## ELT 式压缩与研究叙事

ELT 的价值还包括共享循环替代独立深度，以及不同循环深度间的自蒸馏。后续在质量与理解保真成立后，将外层连续块组或 flow 块组改成固定共享 core，使用循环次数编码与最大循环教师的中间循环自蒸馏，并联合原始任务监督。必须同时比较未压缩骨干、同参数浅模型、同 FLOPs 深模型和固定/弹性循环。

当前 v31 保留了全部28层并增加适配器，参数与计算增加；它验证可训练接口，不等于已经完成参数压缩。最终论文需要证明两个独立贡献：共享循环在更少独立参数下保持/提高生成和理解；理解证据在固定预算内决定把计算投给语义联合表示还是速度场，使质量优于无条件增加循环。

## 质量与成本的证据要求

成功教师仍须同状态官方错→对，且 HPS、Pick 均不低于基线。终点 latent MSE 降低不能替代语义、图像质量或偏好提升。独立 val 报告 GenEval、HPS/Pick/SigLIP、错→对/对→错、提示聚类区间；扩展后补人评、多样性、FID 和视频 FVD。当前这些广域结果没有完成。

分开记录语义编码、Qwen 首访/循环、flow 首访/循环、MMU、VAE、离线教师检测器及实际端到端耗时。v31 的14次剩余前向为392次原 Qwen block、16次重访和140次 flow block。抵达 index35 后为理解检查计算过该时刻速度，再从改变后的外层输入重算，需显式计入这次重复速度；旧 nominal 数字不能代替实测 FLOPs。训练 checkpoint 的反向重算与推理成本分开。

可发表的核心假设是：在统一模型中，理解不是生成结束后的独立评判，而是对生成过程中共享语义计算与速度场计算的可学习分配依据；两者通过同一中途状态与联合监督相互促进。该假设仍需要实验支持，不预先填入正结果。
